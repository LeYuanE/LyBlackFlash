# Ly黑闪 · 特效实现与验收

> 适用版本：`1.0.0-r19`（当前发布版）。本文档记录世界闪电、客户端演出、
> 状态条与熟练度界面的实现方式，以及需要人工确认的验收清单。

## 目标与范围

保留原来的低概率跳跃斩触发、伤害成长、音效、飘字与轻微 FOV 收缩。世界空间闪电采用**粗黑核心、窄红边、薄红晕光、不规则尖端与分叉**。不增加全屏墨迹、镜头翻滚、时间停止、第三方库或后处理着色器。

实现依据是模组设计目录中的《007-演出设计》及 `bf4.png` / `bf5.png` 参考：局部双中心放射、逐渐蔓延、由先至后消散，而不是等宽红色线束。

## 实际效果组成

- 命中目标碰撞箱 60% 高度附近为主中心，保留 r5 工作区内的高度修复。
- 9 条主闪电与 5 条真正连接主干的侧枝；主干长度约 1.85–3.1 格。
- 攻击者可见且距离合理时，增加 4 条拳头小闪电和 1 条拳头至命中点的连接弧。
- 主闪电以攻击方向的横截面向外展开，同时保留随机纵深。正面轮廓清晰，侧面仍是世界空间几何。
- 不同分支具有不同宽度与错开的生长时刻，末端逐渐收尖。线段接缝共用顶点，移动前沿采用插值，不整段跳出。
- 配色以近黑 `#0A0303` 为主，红边 `#AE191B`，低透明度晕光 `#D41E1B`。黑心约占外轮廓宽度的 75%，不使用会让黑色消失的加法混合。

拳头是按实体眼睛、朝向和主手方向估算的位置，不是手部骨骼绑定；不同客户端的实体插值仍可能让这个次中心略有偏差。

## 动画时序

继续使用 `visual` 下的三个原有配置键，无需迁移配置：

| 配置 | 默认值 | 行为 |
|---|---:|---|
| `flashStartMs` | 100 | 快速撑开前 34%，笔触先粗后收 |
| `flashSpreadMs` | 1000 | 连续生长到完整长度，侧枝跟随主干出生 |
| `flashFadeMs` | 600 | 从根部/先出生处向末端依次淡出 |

默认总时长 1700 毫秒，所有节点在移除前均已透明，不再把迟出生分支直接切掉。每项在渲染端限制为 1–10000 毫秒，避免错误配置产生除零或无限驻留，不修改配置文件本身。

时钟使用自定义的单调特效时钟（`FxClock`），而非直接相减世界时间：世界时间会被服务器同步包覆盖，服务器卡顿时同步值可能小于客户端已走过的值，导致正在播放的闪电年龄归零、消失后重新生长。该时钟只在同步值前进时采纳，倒退时忽略，长期偏离时按每帧最多 5 tick 缓慢靠拢。暂停时随游戏一同暂停；切换世界或退出游戏后连同旧闪电一起重置。

飘字、FOV 收缩、被击中屏幕特效、连击/无我 HUD 与无我脉冲**共用同一个时钟**（`FxClock.gameMillis()`，世界时间经 `FxTick` 桥接层喂入），因此客户端演出在暂停/低 TPS 时一致；全部客户端计时都已不再使用现实墙钟。HUD 在 F1 隐藏界面时也一同隐藏。

## 渲染与预算

- `FlashGeometry` 只在生成时按服务端种子构造不可变路径；不在每帧重复随机生成。
- `FlashRenderer` 持有可复用的每帧坐标、宽度、透明度与相机朝向数组，三个材质复用同一份准备结果。
- 在 `AFTER_PARTICLES` 阶段依次整批绘制晕光、红边、黑心。每批显式结束，不交替持有同一个 shared buffer 的 consumer。
- 三层均为 `POSITION_COLOR`、`NO_CULL`、`LEQUAL_DEPTH_TEST`、`COLOR_WRITE`；晕光为加法混合，红边与黑心为标准透明混合。
- **三层输出到主目标，不使用 `PARTICLES_TARGET`**（r7 修正）。粒子目标在 Fabulous 下会拷入不透明深度，而闪电不写深度，导致其在粒子缓冲中的深度等于背后墙面的深度；后续透明合成按这份深度排序，会把闪电之后的玻璃/水画到闪电之上。输出到主目标后，深度测试直接对真实场景深度生效，遮挡始终正确。
- 顶点先减去相机位置，再使用事件的局部 PoseStack；相机旋转由全局 ModelView 提供。不能再把 `getModelViewMatrix()` 乘到顶点上，否则重复旋转。
- 每次完整特效最多 132 段、2112 个顶点；最多保留 24 次特效，总上限 50688 个提交顶点/帧。超限时移除最旧效果，不影响伤害或成长。
- 无特效时提前返回；64 格距离裁剪与包围盒视锥裁剪；过期清理不依赖特效是否进入视野。

这些是几何预算，不是帧率实测或显卡性能保证。没有新增纹理、GL 状态手工切换或外部渲染依赖。

## 联机表现

服务端只给同维度、命中点 64 格内的玩家发送演出，攻击者与玩家受击者保证收到；附近旁观者仍可观看。修复原来“所有维度在线玩家在各自世界显示同坐标闪电”的问题。网络包字段和协议号未改动。

与早期设计文字的差异：旧文档中的“全场可见”现在明确指**同维度附近战斗区域**，不再无距离跨世界广播。旧 `RenderType.lightning()` / `dragonRays()` 实施建议由上述自定义三层材质取代；不是新增后处理系统。

## 预览与真实触发测试

需要开启作弊或具有 OP 等级 2，且 `debug.commandEnabled=true`。

```text
/blackflash preview
/blackflash preview 12345
```

在玩家视线前方 3 格播放世界闪电及触发者的飘字/FOV。可指定种子复现几何，比较昼夜、角度和图形模式时保持位置与朝向相同。**不伤害实体、不消耗 force、不增加熟练度或连击、不触发成就、不播放命中音效**。附近同维度玩家可同时观看。

真实命中链路使用：

```text
/blackflash force
```

随后等待攻击蓄力充满，在下落期间命中活体目标；避免冲刺、水中、骑乘或失明。该指令是“下一次合格暴击必定黑闪”，不是自动攻击或强制把普通攻击改成暴击。

### 实机验收清单

- [ ] 第一人称/第三人称及旁观视角中都能看见；转动相机时效果固定于命中位置。
- [ ] 白天/雪地仍能读出黑色核心，夜晚红边清楚，不是一整条红色粗管。
- [ ] 初段迅速炸开，之后平滑长出；侧枝不提前悬空；末端不突然变粗。
- [ ] 淡出从根部向末端推进，1.7 秒末无明显整体跳灭。
- [ ] 不透明墙体正确遮挡，玻璃/水边缘没有异常残留；**在「极佳」画质下、闪电位于玻璃/水之前时不被其遮挡染色**（r7 修复项，重点复测）。
- [ ] Fast/Fancy/Fabulous 各测试一次；第三方光影与渲染模组需单独兼容测试。
- [ ] 多次重叠预览不崩溃，停止预览后列表按时清空。
- [ ] 暂停/恢复单人世界不跳时，切维度/退出重进不残留旧闪电。
- [ ] **服务器卡顿（可用 `/tick` 或压力测试制造）后，正在播放的闪电不消失、不重新生长**（r7 修复项，重点复测）。
- [ ] **低帧率（限制 FPS 或低配机）下新触发的闪电仍能看出起爆段**（r7 修复项）。
- [ ] **飘字淡出末尾无突然闪亮**（r7 修复项）。
- [ ] **各武器（剑/斧/三叉戟/徒手）连续挥击时，站桩暴击的触发判定与原版暴击表现一致**，尤其冷却刚满的瞬间（r7 修复项）。
- [ ] 第二客户端附近可见，另一维度客户端不可见。
- [ ] `/blackflash force` 实际暴击有音效与世界演出，且原有伤害/成长保持不变。
- [ ] **单人暂停（Esc）或 `/tick freeze` 时，飘字、FOV 收缩、被击中屏幕特效、连击/无我 HUD、无我脉冲与闪电一同冻结**，恢复后继续（r14 变更，重点复测）。
- [ ] **连续触发的连击窗口（5 秒）与无我（10 秒）按游戏时间计**：暂停/冻结期间不消耗窗口；状态包校正后倒计时不跳回（r14 变更）。
- [ ] **K 键打开熟练度面板**，ESC 关闭且世界不暂停；面板严格显示熟练度、累计黑闪、基础概率、今日黑闪四项。
- [ ] **饱食度上方状态条**与原版饱食度行同宽同高：左侧 2/3 淡蓝无我、右侧 1/3 红色连击，无文字；两者失效时整条隐藏。
- [ ] **黑闪连击字**在连续命中时显示 `×2/×3`，每次命中重置动画；预览不伪造连击/无我状态。
- [ ] **无我脉冲只在触发者自己屏幕边缘出现**，附近玩家没有常驻无我光环。
- [ ] **F1 隐藏 HUD**时饱食度上方的状态条/脉冲一同隐藏；重生、换维度、退出重进不残留旧状态。
- [ ] 从 r7 或更早版本**热替换** jar 后，旧的无我会一直生效；`/blackflash reset` 应能清零（重启亦会自然清除）。

## 计时口径（r8 起）

| 层 | 计时基准 | 说明 |
|---|---|---|
| 连击窗口 / 无我持续 / 微反馈节流 | 服务端游戏刻 `Level.getGameTime()` | 配置仍写毫秒，内部按 1 刻 = 50ms 换算 |
| 闪电 / 飘字 / FOV / 被击中特效 / HUD / 无我脉冲 | 客户端 `FxClock.gameMillis()` | 世界时间经 `FxTick` 喂入，单调且暂停冻结 |
| 当日次数（`daily_5` 成就） | `Level.getDayTime() / 24000` | 与游戏日绑定，**不受 `/time set` 之外的变动影响** |

> 注意：`getGameTime()` 与 `getDayTime()` 是两个独立计数。前者只随游戏刻递增，
> 是本次所有演出/窗口计时的基准；后者可被 `/time set` 改动，仅用于「游戏日」概念。

## 离线自动验证

构建需 JDK 21，保留 `neo_version=21.1.219`：

```bash
./gradlew geometryTest --offline
./gradlew build --offline
```

`geometryTest` 是无第三方测试依赖的独立源码集，直接执行生产 `FlashGeometry` 与 `FxClock`。`check` / `build` 自动包含它，覆盖 512 个种子、固定种子复现、分叉连接与出生顺序、有限坐标、范围与段数上限、末端收尖、平滑生长、根到梢淡出、生命周期边界、非法时长保护，以及特效时钟的单调性、同步倒流不重播、缓慢追时与非有限输入隔离。
