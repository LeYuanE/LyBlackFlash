# Ly黑闪 · Ly Black Flash

> 用一次完美的跳跃斩，赌出万分之一的黑色爆发。

改编自《咒术回战》「黑闪」的 Minecraft 模组：玩家用**原版暴击（跳跃斩）**命中生物时，
有**极低概率**触发黑闪，在世界中炸开一道**黑心红边**的闪电。

没有技能键，没有咒力条，没有招式表。你唯一要做的，是继续打——然后等着它发生。

## 效果一览

- **世界层闪电**：命中点炸开 9 条尖端主闪电 + 5 条侧枝，拳头一侧另有 4 条小闪电与 1 条连接弧；
  粗黑核心、窄红边、薄红晕光，从内向外蔓延，再按出生顺序退散。
- **触发者演出**：屏幕下方浮出「黑闪」二字，视野轻微一收（约 220ms）。
- **被击中者演出**：屏幕掠过一层红黑痕迹（比触发者更淡，无飘字）。
- 默认演出约 1.7 秒：100ms 起爆 → 1000ms 蔓延 → 600ms 退散。
- 附近玩家（含旁观者）都能看见闪电；同维度 64 格内广播。

## 机制要点

- **触发条件**：玩家亲手近战 → 真正造成伤害 → 蓄力 > 90% → 构成原版暴击。
  前四条是技术门槛，**只有最后一步是概率**。
- **成长**：基础概率 `0.01% × (已打出次数 + 1)`，每打出一次**永久 +0.01%**，上限 100%。
- **连击**：10 秒内连续触发累积连击，伤害为 `攻击力 ^ (2.5 ^ 连击序号)`；
  **暴击命中却没触发会清空连击**。伤害绕过护甲、抗性与伤害吸收，默认不封顶。
- **无我境界**：触发后 20 秒内概率 ×1.2，可叠加、无上限，每次触发刷新。
- **熟练度与连击死亡不清零**，跟随角色存档；多人各自独立计数。
- 7 个成就，其中「四连闪」「七连闪」「圆满」对应原作彩蛋。

## 快速上手

安装后进入开启作弊（或拥有 OP 等级 2）的世界：

```mcfunction
/blackflash preview          # 在视线前方 3 格预览一次完整演出
/blackflash preview 12345    # 指定种子，复现同一道闪电
```

预览**不造成伤害，不改变熟练度、连击或成就**，也不消耗强制触发。

测试真实链路：

```mcfunction
/blackflash force            # 让下一次「合格暴击」必定触发
```

注意它不会把普通攻击变成暴击，跳跃斩条件仍需自己满足。

## 配置

配置文件 `config/black_flash-common.toml`，注释全中文。可调：总开关、概率增量与上限、
是否必须暴击/满蓄力、伤害上限、击退强度、无我倍率与时长、连击窗口、
各段演出时长与开关、调试指令开关。

> 计时类配置以**毫秒**书写，内部按游戏刻（1 刻 = 50ms）换算。
> 演出与窗口在单人暂停、`/tick freeze`、服务器卡顿时会一同冻结。

## 从源码构建

需要 **JDK 21**。

```bash
./gradlew build              # 联网编译
./gradlew build --offline    # 离线编译（需本地已有依赖缓存）
./gradlew geometryTest       # 单独跑闪电几何与特效时钟检查
```

产物：`build/libs/black_flash-<版本>.jar`。

`build` / `check` 会自动执行 `geometryTest`：一个无第三方依赖的独立源码集，
直接执行生产的 `FlashGeometry` 与 `FxClock`，覆盖 512 个种子、分叉连接、
生长与淡出时序、生命周期边界，以及特效时钟的单调性与时间同步倒流。

## 版本命名

`主版本.次版本.修订版-r构建号`，例如 `1.0.0-r8`。开发阶段以 `-rN` 递增为主。

## 边界

这个模组**不是**咒术回战内容模组：没有咒力槽、没有术式、没有领域、没有咒灵、
没有角色模型、没有新物品或新方块。它只做「一拳打出去，偶尔会变成黑闪」这一件事，
以及围绕它的成长与演出。

命中瞬间定格全场的**时空停滞**规划于 v2，当前版本没有。

## 已知问题

- **音效授权未核实**：`assets/black_flash/sounds/impact.ogg` 的来源授权尚未确认，
  正式公开发布前需要处理。
- **尚未完成实机验收**：开发环境缺少离线启动缓存（`neoforge-21.1.219-moddev-config.json`），
  目前所有验证均为编译期与离线单测级别。画面表现、第三方光影兼容性、
  多人联机与「极佳」画质下的透明遮挡**仍待游戏中确认**。
  完整复测清单见 [docs/特效实现与验收.md](docs/特效实现与验收.md)。
- **跨版本热替换**：`r7 → r8` 之间计时口径由现实时间改为游戏时间，不重启直接换 jar 会让
  旧的无我状态一直生效（重启即恢复）。用 `/blackflash reset` 可手动清零。
