# Ly黑闪 · Ly Black Flash

改编自《咒术回战》「黑闪」的 Minecraft 模组：用**原版暴击（跳跃斩）**命中生物时，
有**极低概率**触发黑闪，在世界中炸开一道**黑心红边**的闪电。

没有战斗技能键，没有咒力条，没有招式表。你唯一要做的，是继续打——然后等着它发生。

## 它会做什么

- **世界层闪电**：命中点炸开 9 条尖端主闪电 + 5 条侧枝，拳头一侧另有 4 条小闪电与 1 条连接弧。
  粗黑核心、窄红边、薄红晕光，从内向外蔓延，再按出生顺序退散。附近玩家（含旁观者）都能看见，
  同维度 64 格内广播。
- **触发者演出**：屏幕下方浮出「黑闪」二字，连击时显示 `×2`、`×3`；视野轻微一收（约 220ms）。
- **状态条**：饱食度上方一行无文字进度条，左侧 2/3 淡蓝为无我境界、右侧 1/3 红色为黑闪连击。
- **无我脉冲**：无我激活时屏幕边缘短暂泛起暗红，仅自己可见。
- **被击中者演出**：屏幕掠过一层红黑痕迹，比触发者更淡、无飘字。
- **熟练度界面**：按 **K** 打开（可在按键设置中改绑），不暂停世界。

默认演出约 1.7 秒：100ms 起爆 → 1000ms 蔓延 → 600ms 退散。

## 机制

**触发**：玩家亲手近战 → 真正造成伤害 → 蓄力 > 90% → 构成原版暴击。
前四条是技术门槛，**只有最后一步是概率**。

**成长**：基础概率 `0.01% × (已打出次数 + 1)`，每打出一次**永久 +0.01%**，上限 100%。
首闪最难——中位玩家约需 2.9 小时。

**连击**：5 秒内连续触发累积连击，伤害为 `本刀伤害 ^ (2.5 ^ 连击序号)`。
**暴击命中却没触发会清空连击**。

**无我境界**：触发后 10 秒内概率 ×1.2，可叠加、无上限，每次触发刷新。

**伤害走原版管线**：附魔、药水、力量效果的加成真正计入基数；护甲、抗性、保护附魔的
减免也照常生效。黑闪只是「这一刀更重」，不绕过任何防御。

熟练度与连击**死亡不清零**，跟随角色存档；多人各自独立计数。

6 个可完成成就：「第一次黑闪」「赤手空拳的奇迹」「四连闪」「一日五闪」「七连闪」「圆满」，
其中后三项对应原作彩蛋。

## 命令

需要作弊或 OP 等级 2。

```mcfunction
/blackflash preview          # 在视线前方 3 格预览一次完整演出
/blackflash preview 12345    # 指定种子，复现同一道闪电
/blackflash force            # 让下一次「合格暴击」必定触发
/blackflash stats            # 查看次数 / 概率 / 段位 / 连击
/blackflash reset            # 清零熟练度与连击
```

`preview` **不造成伤害，不改变熟练度、连击或成就**，也不消耗强制触发，适合先看效果。

`force` 不会把普通攻击变成暴击——跳跃斩条件仍需自己满足。

## 配置

配置文件 `config/black_flash-common.toml`，注释全中文。可调：总开关、概率增量与上限、
是否必须暴击/满蓄力、伤害上限、击退强度、无我倍率与时长、连击窗口、各段演出时长与开关。

状态条、无我脉冲与 K 键界面是客户端固定体验，不提供配置项；K 键可在按键设置中改绑。

> 计时类配置以**毫秒**书写，内部按游戏刻（1 刻 = 50ms）换算。
> 演出与窗口在单人暂停、`/tick freeze`、服务器卡顿时会一同冻结。

## 边界

这个模组**不是**咒术回战内容模组：没有咒力槽、没有术式、没有领域、没有咒灵、
没有角色模型、没有新物品或新方块。它只做「一拳打出去，偶尔会变成黑闪」这一件事。

命中瞬间定格全场的**时空停滞**规划于 v2，当前版本没有。

## 从源码构建

需要 **JDK 21**。

```bash
./gradlew build              # 联网编译
./gradlew build --offline    # 离线编译（需本地已有依赖缓存）
./gradlew geometryTest       # 单独跑闪电几何与特效时钟检查
```

产物：`build/libs/black_flash-<版本>.jar`。

`build` / `check` 会自动执行 `geometryTest`：一个无第三方依赖的独立源码集，直接执行生产的
`FlashGeometry` 与 `FxClock`，覆盖 512 个种子、分叉连接、生长与淡出时序、生命周期边界，
以及特效时钟的单调性与时间同步倒流。

### 版本命名

**当前发布版：`1.0.0-r19`**（已实机验收）。

开发期使用 `发布目标-r迭代号`，例如 `1.0.0-r19`：`1.0.0` 是这一轮打算交付的版本，
`-rN` 是通往它的第 N 次打包。带 `-r` 后缀的都是内测快照，可能被推翻重做。

自 1.0.0 发布后改用标准语义版本，**不再带 `-rN` 后缀**：修复缺陷 → `1.0.1`；
新增功能 → `1.1.0`；不兼容改动 → `2.0.0`。

## 已知问题

- **多人环境验证有限**：当前版本的验收集中在单人环境。多人联机、第三方光影与渲染模组的
  兼容性，以及「极佳」画质下的透明遮挡建议自行复测；
  可参考 [docs/特效实现与验收.md](docs/特效实现与验收.md) 的验收清单。
- **`force` 没有武装状态提示**：`/blackflash force` 生效后没有持续显示，
  `/blackflash stats` 也不反映它；若中途执行 `/blackflash reset` 会被静默清除。

## 从旧版升级

仅在装过内测版（r2–r18）时需要看。首次安装可跳过。

| 变化 | 影响 | 处理 |
|---|---|---|
| 网络协议升至 `2`（r14） | 客户端与服务端**无法混用**旧版 | 完整更新，不要只换一侧 |
| 计时口径改为游戏时间（r8） | 不重启直接换 jar 会让旧无我状态一直生效 | 重启，或 `/blackflash reset` |
| `damageCap` 改为限制减免前伤害（r13） | 按旧语义调过该值的配置会静默变弱 | 按新语义重新设定，见下方说明 |
| 连击窗口 10→5 秒、无我 20→10 秒（r9） | 已生成的配置文件保留旧值 | 手改这两个键，或删掉配置文件重新生成 |
| 成就根节点被删除（r12） | 旧的「Ly 黑闪」条目不再显示 | 无需处理 |

> **关于 `damageCap`**：黑闪伤害从「护甲减免后替换最终值」改为「减免前放大原始伤害」，
> 因此该配置项现在限制的是**减免前**的伤害，最终伤害还会被目标护甲、抗性与保护附魔继续削减。
> 默认值 `0`（不封顶）不受影响；只有按旧语义调过这个值的整合包需要重新设定。
