# Ly黑闪 · Ly Black Flash

改编自《咒术回战》黑闪的Minecraft模组：暴击命中生物，有极低概率触发黑闪，生成黑心红边闪电。 无额外按键、咒力条与招式面板，正常战斗等待触发即可。

## 模组效果

- **世界闪电特效**：命中点生成9道主闪电+5道侧枝，攻击侧附带4道小闪电与1条连接弧；黑核心、红边、红色光晕，按顺序消散。同维度64格内全部玩家可见。
- **攻击者反馈**：屏幕底部显示“黑闪”，连击显示`×2`/`×3`；视野收缩约220ms。
- **状态条**：饱食度上方进度条，左2/3淡蓝=无我境界，右1/3红色=黑闪连击。
- **无我脉冲**：无我境界激活，自身可见屏幕边缘暗红光效。
- **受击者反馈**：目标屏幕划过淡化红黑痕迹，无文字。
- **熟练度面板**：默认按键**K**（可在按键设置修改），打开不暂停游戏。

整套演出默认1.7秒：100ms起爆 → 1000ms蔓延 → 600ms退散。

## 机制

**触发条件**：玩家近战、造成伤害、蓄力＞90%、打出原版暴击。前四项为硬性条件，仅最后触发为概率判定。

**概率成长**：基础概率 `0.01% × (已触发次数 + 1)`，每触发一次永久+0.01%，上限100%。首次触发难度最高，平均约需2.9小时游玩时长。

**连击**：5秒内连续触发叠加连击；伤害公式 `本刀伤害 ^ (2.5 ^ 连击序号)`。

> 暴击命中但未触发黑闪，直接清空连击。

**无我境界**：黑闪触发后10秒，概率×1.2；可无限叠加，每次触发刷新时长。

**伤害**：完全沿用原版伤害管线，附魔、药水、力量正常加成；护甲、抗性、保护附魔正常生效，不绕过防御。

熟练度、连击死亡不清零，存于角色存档，多人模式各人独立。

共6项成就：「第一次黑闪」「赤手空拳的奇迹」「四连闪」「一日五闪」「七连闪」「圆满」，后三项为原作彩蛋。

## 指令

需作弊或OP等级2。

```
/blackflash preview          # 视线前方3格预览完整特效
/blackflash preview 12345    # 指定种子复现闪电
/blackflash force            # 下一次合格暴击必定触发黑闪
/blackflash stats            # 查看次数、概率、段位、连击
/blackflash reset            # 清空熟练度与连击
```

> `preview`不造成伤害、不改动进度；`force`不会生成暴击，仍需满足跳跃斩条件。

## 配置

配置文件：`config/black_flash-common.toml`，全部中文注释。 可配置项：模组开关、概率增量与上限、暴击/满蓄力强制开关、伤害上限、击退、无我倍率时长、连击窗口、演出时长与开关。

> 状态条、无我脉冲、K键面板无需配置，默认启用；K键可改键。 计时配置单位为毫秒，内部自动转为游戏刻（1刻=50ms）。暂停、时间冻结、服务器卡顿，特效计时同步冻结。

## 模组定位

本模组非完整咒术回战内容模组，无咒力、术式、领域、咒灵、新模型、物品、方块，仅实现暴击触发黑闪。 命中时空停滞规划于v2，当前版本无该功能。

## 源码构建

依赖 **JDK 21**

```
./gradlew build              # 联网编译
./gradlew build --offline    # 离线编译（本地需有依赖缓存）
./gradlew geometryTest       # 闪电几何与特效时钟单元测试
```

产物路径：`build/libs/black_flash-<版本>.jar`

`build`/`check`会自动运行`geometryTest`，校验闪电生成、特效时序与边界逻辑。

### 版本命名

当前版本：`1.0.0‑r19`（实机验收） 内测格式：`版本-r迭代号`，带`‑r`为内测快照，可能改动。 正式发布后采用语义化版本：修复bug升第三位；新增功能升第二位；破坏性不兼容改动升第一位。

## 已知问题

- 多人联机验证较少；光影、渲染模组、极佳画质下透明遮挡请自行测试。
- `/blackflash force`无UI提示，`stats`不显示该状态；执行`reset`会静默清除强制触发。

## 内测版升级（r2‑r18，首次安装跳过）

| 改动                             | 影响                            | 处理方案                         |
| -------------------------------- | ------------------------------- | -------------------------------- |
| 网络协议升级2(r14)               | 新旧端不互通                    | 客户端服务端全部更新，勿单改一端 |
| 计时改为游戏时间(r8)             | 直接替换jar，旧无我buff永久生效 | 重启或执行`/blackflash reset`    |
| damageCap改为限制减免前伤害(r13) | 旧自定义配置会变弱              | 重新调整参数；默认0不受影响      |
| 连击窗口10→5秒，无我20→10秒(r9)  | 旧配置保留原值                  | 手动修改或删除配置文件重生成     |
| 移除成就根节点(r12)              | 旧分类条目消失                  | 无需处理                         |

> damageCap说明：现限制护甲计算**之前**的伤害上限，最终伤害依旧会被防御效果削减。
